tsuburu — 시작하기 / Getting started
====================================

[한국어]

1. 이 폴더의 start.sh 를 실행하세요.
   파일 관리자에서 더블클릭하거나, 터미널에서:  ./start.sh

2. 브라우저가 열립니다. 안 열리면 주소창에 직접 입력하세요:
   http://127.0.0.1:8420/

대사 검색까지 쓰려면 도구 두 개가 필요합니다:
   sudo apt install tesseract-ocr tesseract-ocr-kor ffmpeg

끄려면 터미널에서 Ctrl-C를 누르세요.

설치되는 것은 없습니다. 이 폴더를 지우면 프로그램이 사라집니다.


[English]

1. Run start.sh in this folder — double-click it in your file manager,
   or in a terminal:  ./start.sh

2. A browser opens. If it does not, go to http://127.0.0.1:8420/

For dialogue search, two tools are needed:
   sudo apt install tesseract-ocr tesseract-ocr-kor ffmpeg

Press Ctrl-C in the terminal to stop it.

Nothing is installed. Deleting this folder removes the program.
